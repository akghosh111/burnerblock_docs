---
title: API Keys
description: Managing your BurnerBlock API keys.
---

To get an API key:
1. Go to the [BurnerBlock Dashboard](https://www.burnerblock.pro/).
2. Click on "Generate API Key".
3. Copy the key and store it securely.

:::caution
You can only view your API key once. If you lose it, you'll need to generate a new one.
:::
